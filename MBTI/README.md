# 🌍 글로벌 비즈니스(무역+경영) MBTI 테스트

무역 실무와 경영 기획 상황을 바탕으로 나의 비즈니스 리더십 성향을 알아보는 **인터랙티브 웹 심리테스트**입니다. 파이썬 [Streamlit](https://streamlit.io/)을 기반으로 제작되었습니다.

## ✨ 주요 기능 (Features)
- **👋 애니메이션 인트로:** 시작 전 사용자들의 흥미를 끄는 귀여운 바운스 애니메이션 이모지와 인사말.
- **⏱️ 30초 타이머 자동 스킵:** 각 문항당 30초의 제한 시간이 있으며, 시간이 초과되면 자동으로 다음 문항으로 넘어갑니다. (거슬리는 텍스트 커서 제거 완료!)
- **🎨 맞춤형 프로필 카드:** 16가지 결과에 맞춰 `DiceBear API`를 활용한 귀여운 이모지 캐릭터와 명함 형태의 결과 카드를 제공합니다.
- **📊 상세 성향 게이지 바:** 단순한 MBTI 결과뿐만 아니라, E/I, S/N, T/F, J/P의 세부 비율(%)을 양방향 게이지 그래프로 직관적으로 보여줍니다.
- **🤝 찰떡궁합 & 상극 파트너:** 나와 잘 맞는 비즈니스 파트너와 부딪히기 쉬운 파트너 유형을 추천해 줍니다.
- **💼 직무 추천 & 채용공고 연동:** 결과에 맞는 무역/경영 직무 3가지를 추천하고, 각 직무의 상세 설명과 함께 **사람인(Saramin) 채용공고 원클릭 검색 버튼**을 제공합니다.
